##📋 Insight Place — Estudo de MySQL (Oracle ONE)
Projeto prático desenvolvido durante o curso MySQL: Conhecendo a Ferramenta, parte da formação do programa Oracle Next Education (ONE) em parceria com a Alura.

##📋 Sobre o projeto
A Insight Place é uma plataforma fictícia de aluguel de hospedagens por temporada. O desafio do projeto foi migrar o banco de dados da empresa para o MySQL, estruturando tabelas, inserindo dados e criando consultas para apoiar decisões estratégicas de marketing e negócio.
Objetivos trabalhados

##📋Instalação e configuração do MySQL e MySQL Workbench
Acesso ao MySQL via linha de comando
Criação do banco de dados e tabelas do zero
Inserção e manipulação de dados
Consultas SQL para extração de insights
Modificações estruturais no banco de dados


##📋Tecnologias

MySQL 8.0
MySQL Workbench
